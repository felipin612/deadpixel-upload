# Dead Pixel Uploader – Privacy Policy

Dead Pixel Uploader is a private tool used only by the owner of the Dead Pixel Studios YouTube channel.
It uses the YouTube Data API to set thumbnails, the altered/synthetic content flag and playlists on the owner's own videos.
It does not collect, store or share data about any other person. OAuth credentials are kept as encrypted GitHub Actions secrets and are used only by this repository's workflow.
